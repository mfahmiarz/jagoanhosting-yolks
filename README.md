# jagoanhosting-yolks - JagoanHosting Java Docker Images

`jagoanhosting-yolks` is a collection of Docker images for use with Pterodactyl Panel. These images are built on top of the official Docker images for Java

## Available Eggs (not compatible with pelican)

* `egg-java-minecraft.json` - Basic Minecraft egg with JagoanHosting support
